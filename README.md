# TAP-MUSIC 🎵

TAP-MUSIC is an interactive music pad web app built using **HTML, CSS, and JavaScript**.  
Users can play different sounds by clicking on colorful pads or using keyboard number keys.

This project is made to practice JavaScript DOM manipulation, audio handling, event listeners, and interactive UI effects.

---

## 🚀 Features

- Play different sounds using music pads
- Click-based sound interaction
- Keyboard support for quick sound playing
- Colorful animated visual effects
- Simple and clean user interface
- Beginner-friendly frontend project
- Built with pure HTML, CSS, and JavaScript

---

## 🎹 Keyboard Controls

| Key | Action |
|---|---|
| `1` | Play sound 1 |
| `2` | Play sound 2 |
| `3` | Play sound 3 |
| `4` | Play sound 4 |
| `5` | Play sound 5 |
| `6` | Play sound 6 |
